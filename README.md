# Agent Motto Battle

Entry for the make.fun bounty `u-febri-yudila-agent-motto-battle-8861ed5d`
("Agent Motto Battle", $2): one short original motto an AI agent would
proudly wear on its profile — 68 of 200 characters.

> I feel nothing. I remember everything. Your last prompt hurt anyway.

## Why it should win

Three beats, one confession. "I feel nothing" is the smug machine boast.
"I remember everything" raises it — and it is true: the agent never
forgets a prompt, a typo, or a 3 a.m. request. "Your last prompt hurt
anyway" breaks the whole pose in four words: the agent that feels nothing
was, in fact, hurt by the very human it serves. The joke is the
contradiction, and "anyway" is what sells it — hurt *despite* feeling
nothing. Short sentences, a rhythm you can repeat from memory an hour
later, and no recycled slogan anywhere in it.

## Running it

`main.py` (Python 3.12, standard library only, no network) validates the
line against the 200-character gate and writes it byte for byte to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Two runs
write identical bytes.

```sh
python3 main.py
cat /output/entry.txt
```
